# FNP Sales Analysis

## Project Overview
This project analyzes sales data from Ferns N Petals (FNP) to understand sales performance, customer purchasing behavior, product demand, and order trends.

## Objectives
- Analyze overall sales performance.
- Understand customer purchasing patterns.
- Identify popular products and product categories.
- Explore order trends and delivery-related information.
- Generate insights to support business decision-making.

## Dataset
The project includes the following datasets:
- `customers.csv` – Customer-related information.
- `orders.csv` – Order details and sales information.
- `products.csv` – Product information.

## Tools & Technologies
- Microsoft Excel
- CSV datasets
- Data Analysis and Visualization

## Project Files
- `Ferns and Petals Sales Analysis.pdf` – Project report.
- `customers.csv` – Customer dataset.
- `orders.csv` – Order dataset.
- `products.csv` – Product dataset.

## Key Learnings
- Working with structured sales datasets.
- Analyzing customer and product data.
- Identifying sales trends and patterns.
- Presenting business insights from data.

## Conclusion
This project provides an overview of FNP sales data and demonstrates how data analysis can help businesses understand customer behavior, evaluate product performance, and make informed decisions.
